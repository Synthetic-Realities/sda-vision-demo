SDA Vision

A research tool for examining synthetic media, content credentials and model interpretations, with community and facilitator activities.

Dr Sam Martin (she/her), Smart Data Research UK (UKRI) Fellow, Manchester Metropolitan University. ORCID.

This work was supported by Smart Data Research UK, a UKRI investment; Grant number UKRI4010.

What this demo covers

Choose from ten prepared examples. All ten have recorded Claude, OpenAI and Gemini assessments. The PDF and presentation use four sampled images each; the podcast assessment covers a transcript excerpt, rather than AI-origin detection from sound. Dates and check coverage are retained in each report. Scores are research heuristics, not calibrated probabilities.

The website loads saved results. It has no visitor file uploads and makes no new analysis-provider calls. Pasted Second Opinion replies and session responses stay in browser memory until reset or reload; download them to retain a copy. Browser display preferences are stored locally. GitHub Pages records visitor IP addresses for security; GitHub’s privacy terms apply. External assistant links open separate services; sending material there is a separate action.
