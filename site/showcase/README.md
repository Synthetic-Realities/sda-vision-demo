# SDA Vision: ten-example saved-results demo

Seven images, one PDF, one PPTX and one podcast. Descriptive filenames indicate the type of material without naming its creator, generation service or source classification. Copies retain original bytes, embedded metadata, signatures and visible credits.

All ten examples now have fresh recorded Claude, OpenAI and Gemini assessments from the September 2026 refresh. Images were assessed individually; the PDF and presentation used four sampled images each. Podcast content was assessed from the first 12,000 characters (or less) of a fresh transcription; the report retains the first 4,000 characters and states its exact coverage. AI-origin detection from the sound itself is outside this workflow. Acquisition dates, models, uncertainty and local credential checks are recorded separately. Earlier reports remain preserved in the private preparation records and Git history.

The manifest records exact SHA-256 checksums. Originals sit alongside this file in the repository and in originals/ in a preparation bundle. See CREDITS.md for required attribution. See the separate media terms before onward reuse. The private facilitator source key is stored separately.
